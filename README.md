# Texas Hold'em (Python)

텍사스 홀덤 게임 로직의 **기본 엔진 + 콘솔 데모**입니다.

## 포함된 기능
- 52장 카드 덱 생성/셔플/딜
- 7장(홀카드 2 + 보드 5) 기준 최적 5장 족보 계산
- 족보 비교를 통한 승자 판정
- 간단한 콘솔 시뮬레이션 (`You` + 봇들)

## 실행 방법
```bash
python holdem.py
```

## 테스트
```bash
python -m pytest -q
```
